# Patrick Grossmann — Strategic Advisory

Single-page website built with HTML, CSS, JavaScript and Three.js.

## Run locally

1. Install Node.js.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `npm ci` in the terminal.
5. Open `index.html` using the Live Server extension.

Use a local web server rather than opening the HTML by double-clicking.
Internet access is required for external fonts, booking and remote images.
